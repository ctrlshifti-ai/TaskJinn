TaskJinn

The ultimate task management tool for freelancers.

Boards, time tracking, timesheets and invoices. For macOS, Windows and Linux.

Download View on GitHub

Free and open source · GPL-3.0

Try it

Drag a card to another column, or press ▶ to start its timer.

Features

🗂️

Organizations → projects → tasks

Each project numbers its tasks (WEB-1, WEB-2…) and has a board with To Do, In Progress, In Review and Done.

⏱️

Start, pause, stop

Every session is saved. Run several timers at once, and see the running time in the menu bar.

📈

Status history

See when a task was started and finished, and how long it spent in each status.

📝

Rich text

Descriptions and comments with headings, lists, checklists, code and pasted images.

🧾

Timesheets and invoices

Generate Excel timesheets and invoices for weekly, bi-weekly or monthly periods, with your signature.

🔒

Your data stays local

Each organization is a folder with a SQLite database you choose. No account, no cloud.

Get started

  1. Download the installer for your system from Releases.
  2. Create an organization and choose a folder to store it.
  3. Add a project and tasks, then press ▶ to track time.

Prefer to build it yourself? Install Rust, then:

git clone https://github.com/ctrlshifti-ai/TaskJinn.git
cd TaskJinn
./scripts/build-mac.sh      # or build-linux.sh, or build-windows.ps1
